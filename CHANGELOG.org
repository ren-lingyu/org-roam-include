Changes since v0.1.0.

** Changed
- *Breaking:* Move the library into =lisp/=. Update manual =load-path=
  entries and direct =load-file= calls to use that directory. The public
  entry remains =(require 'org-roam-include)=.
- Lower the declared minimum Emacs version from 31.0 to 30.1.

** Added
- A Nix flake with named =org-roam-include= and =emacs= packages for the
  library and an Emacs wrapper, plus a development shell containing the
  library and its dependencies. Use =nix build .#org-roam-include= or
  =nix build .#emacs=; no default package is provided. Packaging uses the
  personal-nixpkgs framework, Nixpkgs' =melpaBuild= helper and the default
  Nixpkgs Emacs package set.
- An exported =overlays.emacsPackages= overlay for downstream Emacs package
  sets and =legacyPackages.<system>= outputs for the configured package set.
- A =nix flake check= workflow that builds the package, runs ERT against the
  built library and real Org-roam dependency, checks the source with
  package-lint and validates repository formatting with treefmt.

[[file:CHANGELOGS/v0.1.0.org][Detailed release notes]]

Initial release. Requires Emacs 31.0 or later, Org 9.7 or later and Org-roam
2.0.0 or later.

** Added
- Resolve =#+ROAM_INCLUDE: NODE-ID= wrappers for file and headline nodes to
  native Org INCLUDE targets using Org-roam database locations and saved
  source files. Preserve native arguments such as =:lines=, =:only-contents=
  and =:minlevel= for Org to interpret.
- Project a file node's outline from its first real headline through the end
  of the file, excluding preceding file metadata and introductory content.
  Report an error when the target file has no headline.
- Mount file-node outlines through a local headline's =ROAM_INCLUDE=
  property. Preserve the local headline and other properties while replacing
  its body and descendants and removing the controlling property in the
  export copy.
- Support recursive mixtures of native INCLUDE, Org-roam wrappers and
  file-node mounts through Org's native expansion. Leave line selection,
  heading levels, links, footnotes and cycle handling to Org.
- Respect subtree export, COMMENT subtrees and literal blocks. Discard
  replaced mount content before resolving wrappers within it.
- Provide the global =org-roam-include-mode= for export-only normalization
  and =org-roam-include-check-setup= for setup diagnostics. Failed setup
  checks warn and leave the mode disabled; disabling removes its export
  integration without changing source files.
- Diagnose empty or missing node IDs, unreadable files, structurally invalid
  database locations and unsupported headline-node property mounts, without
  automatic database synchronization or fallback identity searches.
